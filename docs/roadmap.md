> 작성일: 2026-11-09 · 최종 갱신: 2026-11-09

|---|---|

> **진행 순서 메모** — Phase 3(인증)보다 4~7(화면)을 먼저 진행했습니다.

## 향후 확장 (범위 밖 · 교체 지점만 확보)

로드맵에 포함하지 않되, **구조적으로 막히지 않게** 설계해 둡니다.

| 확장 | 현재 상태 | 전환 방법 |
|------|----------|----------|
| 실 API 연동 | 목업 구현 | `data/http/` 구현체 추가 후 바인딩 1곳 교체 |
| FCM 푸시 수신 | 알림 화면만 구현 | `expo-notifications` + 백엔드 FCM 토큰 등록 API |
| WebSocket 채팅 | 송수신 흐름만 구현 | STOMP 클라이언트로 Repository 구현체 교체 |
| 실제 사진 라이브러리 | 더미 미디어 그리드 | `expo-image-picker` 로 미디어 소스 교체 |
| 파일 업로드 (S3) | 목업 응답 | presigned URL 발급 API 연동 후 업로드 구현체 추가 |
| 소셜 로그인 | 미구현 | Expo AuthSession + 각 SDK |
