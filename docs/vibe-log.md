# 바이브 코딩 세션 기록

이 저장소의 코드는 전부 자연어 프롬프트 지시로 [Claude Code](https://claude.com/claude-code)가 작성했습니다.
배경과 역할 분담은 [README의 해당 절](../README.md#어떻게-만들어졌나--바이브-코딩-기록)에 있고,
여기에는 **세션별 작업 내역**을 쌓습니다.

기록 단위는 **세션**입니다. 대화 한 번에 끝난 작업을 한 항목으로 묶습니다.

각 항목은 네 가지를 남깁니다.

| 항목 | 왜 남기는가 |
|---|---|
| **지시** | 사람이 무엇을 요구했는지 — 프롬프트의 추상도를 보여준다 |
| **변경** | 실제로 무엇이 바뀌었는지 |
| **에이전트가 잡아낸 것** | 지시받지 않았으나 발견해 고친 것 — 없으면 "없음" |
| **검증** | 무엇으로 확인했는지 — 이것이 없으면 나머지는 주장일 뿐이다 |

## 세션 1 — 초기 구축

**2026-10-13 ~ 10-14**

### 지시

> "포폴용 앱을 안드로이드에서 리액트 네이티브로 하이브리드 플랫폼 앱으로 전환하고 싶어.
> 포폴용 앱의 특성을 고려하고, 최신 리액트 네이티브 개발 트렌드에 맞게 프레임워크를 제작해줘.
> 포폴용 앱을 개발 정의서를 작성해줘."

이후 같은 세션에서 추가된 지시 — iOS 시뮬레이터로 기기 테스트, 스크린샷 캡처 후 README 삽입,
커밋 정리, 바이브 코딩 이력 명시.

### 변경

빈 저장소에서 전 화면이 동작하는 앱까지.

- **스택 선정** — Expo SDK 57 · RN 0.86.3 · React 19.2.3 (New Architecture)
  · Expo Router · TanStack Query · Zustand · NativeWind 4 · Reanimated 4 · FlashList 2
- **디자인 시스템** — Compose의 색·치수 토큰을 CSS 변수로 이식, 라이트/다크 2벌
- **데이터 계층** — 도메인 모델 5종, Repository 인터페이스 + 인메모리 구현, 교체 지점 1곳
- **화면 전부** — 스플래시 · 피드 · 게시물 상세 · 검색 · 활동 · 프로필(내/타인)
  · 메시지 목록 · 대화방 · 설정
- **문서** — 개발 정의서(README) + iOS 시뮬레이터 스크린샷 9장
- **커밋 정리** — Expo 템플릿 커밋을 걷어내고 레이어 단위 5개로 재구성

### 에이전트가 잡아낸 것

| 발견 | 조치 |
|---|---|
| 페이지 인디케이터가 배열 인덱스를 `key`로 써서 린트 경고 | 억제 대신 **미디어 id 목록을 받도록 API 변경** |
| README가 `expo-image`를 스택으로 소개했으나 실제 미사용 | "도입 시 사용 예정"으로 정정 |
| LICENSE 저작권자가 Expo(650 Industries) 그대로 | 본인 명의 MIT로 교체 |
| `.vscode` 설정이 ESLint 기준이라 Biome 스택과 불일치 | Biome 액션으로 교체 |
| 활동 화면은 진입 즉시 읽음 처리되어 "미읽음 표시"를 볼 수 없음 | 문서 서술을 실제 동작에 맞게 수정 |
| 디자인 토큰이 CSS와 TS 두 곳에 복제됨 | 복제 제거 대신 **일치를 강제하는 테스트** 추가 |

### 검증

- `tsc --noEmit` 통과 · Biome 경고 0 · 테스트 16개 통과
- iOS 번들 빌드 확인 (3,737 모듈)
- **iPhone 17 / iOS 26.5 시뮬레이터 실기 확인** — 전 화면 이동, 다크 모드 전환까지
- README의 서술이 실제와 맞는지 역검증 (수치·경로·동작)
