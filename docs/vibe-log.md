# 바이브 코딩 세션 기록

이 저장소의 코드는 전부 자연어 프롬프트 지시로 [Claude Code](https://claude.com/claude-code)가 작성했습니다.
배경과 역할 분담은 [README의 해당 절](../README.md#어떻게-만들어졌나--바이브-코딩-기록)에 있고,
여기에는 **세션별 작업 내역**을 쌓습니다.

기록 단위는 **세션**입니다. 대화 한 번에 끝난 작업을 한 항목으로 묶습니다.

각 항목은 네 가지를 남깁니다.

| 항목 | 왜 남기는가 |
|---|---|
| **지시** | 사람이 무엇을 요구했는지 — 프롬프트의 추상도를 보여준다 |
| **변경** | 실제로 무엇이 바뀌었는지 |
| **에이전트가 잡아낸 것** | 지시받지 않았으나 발견해 고친 것 — 없으면 "없음" |
| **검증** | 무엇으로 확인했는지 — 이것이 없으면 나머지는 주장일 뿐이다 |

## 세션 3 — 프로필 완성

**2026-11-09**

### 지시

> "로드맵 문서 기반으로 다음 신규/추가 개발해야 할 기능이 뭔지 알려줘."
> → 우선순위를 제시한 뒤 "진행해."

### 변경

로드맵 Phase 6-2 중 **죽어 있던 자리**를 메웠다.

- `프로필 편집` 화면 신설 — 이름 · 아이디 · 소개. 아이디는 영문 소문자 규칙 검사,
  중복이면 **서버가 거절**하고 화면은 그대로 머문다
- `팔로워 / 팔로잉` 목록 신설 — 한 화면 2탭. 진입 탭은 프로필에서 누른 지표가 정한다
- `UserRepository.updateMe()` 계약 추가. 더미 구현은 `syncUserEverywhere` 로
  게시물 작성자 · 댓글 작성자 · 대화 상대까지 한 번에 갱신
- `useUpdateMe()` 는 **낙관적 업데이트를 쓰지 않는다** — 중복으로 거절될 수 있어
  서버가 확정한 값만 캐시에 넣는 쪽이 되돌릴 일이 적다
- `docs/roadmap.md` 를 실제 구현 상태로 동기화 (Phase 9개 전부 대조)

### 에이전트가 잡아낸 것

| 발견 | 조치 |
|---|---|
| `프로필 편집` 버튼에 `onPress` 가 없어 눌러도 아무 일이 없었음 | 이번 작업의 출발점. 편집 화면을 만들어 연결 |
| `useFollowers` · `useFollowing` 훅이 정의만 되고 아무 화면도 쓰지 않음 | 팔로워/팔로잉 목록 화면에서 소비 |
| 팔로워·팔로잉 숫자가 표시만 되고 누를 수 없었음 | `Metric` 에 선택적 `onPress` 를 더해 누를 수 있는 지표로 |
| `resetDb()` 가 "테스트를 깨끗한 상태로 시작시킨다"는 주석과 함께 정의돼 있으나 아무도 호출하지 않음 | `beforeEach(resetDb)` 로 연결 — 케이스 간 간섭 제거 |
| 로드맵 체크박스가 전부 `[ ]` 라 완료된 Phase 1·2·5 도 미착수로 읽힘 | 코드와 1:1 대조해 상태 갱신 |

### 검증

- `tsc --noEmit` 통과 · Biome 경고 0 · 테스트 **33개** 통과 (프로필 수정 3개 신규)
- 산출물 수치 낡음 감지 테스트가 먼저 실패 → `npm run stats` 로 갱신 후 통과
- iPhone 17 / iOS 26.5 시뮬레이터 실기 확인
  - 팔로워 지표 → 목록 진입, 팔로잉 탭 전환
  - 이미 쓰이는 아이디로 저장 → **"이미 사용 중인 아이디입니다"** 표시 후 화면 유지
  - 정상 저장 → 프로필 헤더와 **게시물 상세의 작성자**가 함께 `@loop_kim` 으로 갱신

### 커밋


## 세션 2 — 글쓰기 흐름

**2026-11-04**

### 지시

> "이 Loop 앱에 추가로 진행할 요소가 뭐가 있을까? 쇼미 안드로이드 앱을 참고해서 찾아줘."
> → 후보를 추린 뒤 "1순위 진행해줘."

### 변경

읽기 전용이던 앱에 **생성 경로**를 넣었다.

- `feature:write` 신설 — 미디어 선택 · 미리보기 · 본문 3단계 + 위치 선택
- 바텀 탭 4개 → 5개, 가운데 `+` 는 탭이 아니라 모달로 진입
- `FeedRepository.createPost()` 계약 추가, 더미 구현은 피드 맨 앞에 삽입
- 해시태그 파서를 순수 함수로 분리(추출·입력 중 토큰 판정·추천 적용)
- 초안은 Zustand 가 공유하되 **영속하지 않음** — 설정 스토어와 의도가 다르다

상품 연동·별점·쇼핑 후기 분류는 제외했다.

### 에이전트가 잡아낸 것

| 발견 | 조치 |
|---|---|
| 미리보기의 가로 ScrollView 가 세로로도 늘어나 안내문구가 화면 끝으로 밀림 | 높이를 묶어 고정 |
| 등록 후 `dismissAll()` 이 모달을 닫지 않고 글쓰기 첫 화면으로 되돌아감 | 중첩 스택만 비우는 동작이라 루트 스택을 한 번 더 닫음 |
| 등록해도 새 글이 피드 맨 위에 보이지 않음 | FlashList v2 의 `maintainVisibleContentPosition` 기본 활성이 원인. 라이브러리 기본 동작임을 타입 정의에서 확인한 뒤, 갱신된 data 도착 후 스크롤하도록 수정 |
| 린트가 `src` 만 검사해 생성 스크립트를 건너뜀 | 검사 대상에 `scripts` 포함 |

### 검증

- `tsc --noEmit` 통과 · Biome 경고 0 · 테스트 **30개** 통과(해시태그 10 · createPost 3 신규)
- iPhone 17 / iOS 26.5 시뮬레이터 — 4개 화면 전부 실기 확인
- 피드 복귀 동작은 **사용자가 직접 확인 후 승인**

### 커밋

```

```

## 세션 1 — 초기 구축

**2026-10-13 ~ 10-14**

### 지시

> "포폴용 앱을 안드로이드에서 리액트 네이티브로 하이브리드 플랫폼 앱으로 전환하고 싶어.
> 포폴용 앱의 특성을 고려하고, 최신 리액트 네이티브 개발 트렌드에 맞게 프레임워크를 제작해줘.
> 포폴용 앱을 개발 정의서를 작성해줘."

이후 같은 세션에서 추가된 지시 — iOS 시뮬레이터로 기기 테스트, 스크린샷 캡처 후 README 삽입,
커밋 정리, 바이브 코딩 이력 명시.

### 변경

빈 저장소에서 전 화면이 동작하는 앱까지.

- **스택 선정** — Expo SDK 57 · RN 0.86.3 · React 19.2.3 (New Architecture)
  · Expo Router · TanStack Query · Zustand · NativeWind 4 · Reanimated 4 · FlashList 2
- **디자인 시스템** — Compose의 색·치수 토큰을 CSS 변수로 이식, 라이트/다크 2벌
- **데이터 계층** — 도메인 모델 5종, Repository 인터페이스 + 인메모리 구현, 교체 지점 1곳
- **화면 전부** — 스플래시 · 피드 · 게시물 상세 · 검색 · 활동 · 프로필(내/타인)
  · 메시지 목록 · 대화방 · 설정
- **문서** — 개발 정의서(README) + iOS 시뮬레이터 스크린샷 9장
- **커밋 정리** — Expo 템플릿 커밋을 걷어내고 레이어 단위 5개로 재구성

### 에이전트가 잡아낸 것

| 발견 | 조치 |
|---|---|
| 페이지 인디케이터가 배열 인덱스를 `key`로 써서 린트 경고 | 억제 대신 **미디어 id 목록을 받도록 API 변경** |
| README가 `expo-image`를 스택으로 소개했으나 실제 미사용 | "도입 시 사용 예정"으로 정정 |
| LICENSE 저작권자가 Expo(650 Industries) 그대로 | 본인 명의 MIT로 교체 |
| `.vscode` 설정이 ESLint 기준이라 Biome 스택과 불일치 | Biome 액션으로 교체 |
| 활동 화면은 진입 즉시 읽음 처리되어 "미읽음 표시"를 볼 수 없음 | 문서 서술을 실제 동작에 맞게 수정 |
| 디자인 토큰이 CSS와 TS 두 곳에 복제됨 | 복제 제거 대신 **일치를 강제하는 테스트** 추가 |

### 검증

- `tsc --noEmit` 통과 · Biome 경고 0 · 테스트 16개 통과
- iOS 번들 빌드 확인 (3,737 모듈)
- **iPhone 17 / iOS 26.5 시뮬레이터 실기 확인** — 전 화면 이동, 다크 모드 전환까지
- README의 서술이 실제와 맞는지 역검증 (수치·경로·동작)
